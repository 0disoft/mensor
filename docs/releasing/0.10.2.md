## Compatibility

Human `check` and `compile` failures for missing project contracts now name
the selected root-relative config path and suggest checking the root or
`--config`, or creating the project and referenced feature contracts.
Missing parent directories are covered; missing project roots, unrelated
feature files, permission errors and wrong file types do not get this hint.

No files are generated or reread. Existing JSON envelopes, public APIs,
`path.missing`, filesystem failure classification and exit status 3 remain
unchanged. Producer metadata reflects the package version. Valid projects
require no migration.
