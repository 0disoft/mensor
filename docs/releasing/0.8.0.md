# Migrating to 0.8.0

Version `0.8.0` adds one explicitly invoked TypeScript tagged-template
FormIndex producer. Existing project contracts and static HTML behavior remain
compatible.

Upgrade the fixed package set together:

- `@0disoft/mensor-contract@0.8.0`
- `@0disoft/mensor-compiler@0.8.0`
- `@0disoft/mensor-cli@0.8.0`
- `@0disoft/mensor-reference-runtime@0.8.0`

Generate an index from one or more explicit source files:

```text
pnpm exec mensor index-ts-forms . --source src/views/tasks.ts --tag html
```

The default artifact is `mensor.form-index.json`. Add that root-relative path
as `formIndex` in `mensor.project.jsonc`, then use the TypeScript source path in
the feature action's `form.template`.

The selected tag must be a JavaScript identifier. Matching is syntactic, and
each explicit source must contain at least one selected tagged template.
No-substitution templates are indexed statically. Interpolation is preserved
as incomplete evidence and will fail closed when the document is linked by a
feature contract. The command never imports or executes source.
