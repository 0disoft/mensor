# Migrating to 0.4.0

Version `0.4.0` adds a bounded public reference consumer for RuntimeManifest
v1. Existing contract, compiler, and CLI consumers do not need source changes.

## Packages

Upgrade the fixed public package set together:

- `@0disoft/mensor-contract@0.4.0`
- `@0disoft/mensor-compiler@0.4.0`
- `@0disoft/mensor-cli@0.4.0`
- `@0disoft/mensor-reference-runtime@0.4.0`

## Runtime Consumer Impact

The reference runtime requires an exact action handler registry and an
`actionGuard` whenever the manifest contains POST actions. It accepts only
bounded `application/x-www-form-urlencoded` bodies and returns generic HTTP
errors for invalid input or host failures. Authentication, CSRF verification,
sessions, cookies, persistence, HTML escaping, and deployment stay host-owned.

Applications that use only `mensor check` or `compileProject` may upgrade
without adopting the runtime package.

## Rollback

Projects that have not adopted the reference runtime can pin the original
three-package set back to `0.3.0`. A project using the new package must replace
its runtime consumer before downgrading; do not mix fixed package versions.
