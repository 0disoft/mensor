# Migrating to 0.2.1

Version `0.2.1` is a documentation and release-validation patch. It adds
package-specific npm guides and verifies that those guides are present in the
published tarballs. It does not change Mensor's public APIs, schemas,
diagnostics, manifest format, or CLI behavior.

## Packages

Upgrade the fixed package set together:

- `@0disoft/mensor-contract@0.2.1`
- `@0disoft/mensor-compiler@0.2.1`
- `@0disoft/mensor-cli@0.2.1`

## Consumer Impact

Existing `0.2.0` project contracts, Check Output v1 and v2 consumers, and CLI
commands continue to work unchanged. The npm package pages now show guidance
owned by each package instead of relying only on the repository root README.

## Rollback

If packaging or publication fails before approval, reject the staged release
and keep `0.2.0` on the `latest` tag. After publication, consumers can pin the
fixed package set back to `0.2.0`; do not mix package versions or unpublish a
version that may already have been fetched.
