# Migrating to 0.7.0

Version `0.7.0` publishes FormIndex v1 and lets projects supply one canonical,
source-bound template fact artifact without granting producer execution.

Upgrade the fixed package set together:

- `@0disoft/mensor-contract@0.7.0`
- `@0disoft/mensor-compiler@0.7.0`
- `@0disoft/mensor-cli@0.7.0`
- `@0disoft/mensor-reference-runtime@0.7.0`

Existing static HTML projects require no changes. To use an external template
producer, set project `formIndex` to a project-root-relative canonical JSON
artifact and let feature `form.template` name the indexed source document.
The compiler rejects stale digests, undiscovered source, invalid ranges,
missing linked documents, and unresolved evidence before a project can pass.

Version 0.7.0 does not include a dynamic-template producer. Publishing and
ingesting the artifact first keeps producer support independently reviewable.
