# Migrating to 0.3.0

Version `0.3.0` expands Feature Contract v1 with serializable schema and form
decoder variants for base-10 integers, finite decimals, checkboxes, enums, and
repeated scalar values.

## Packages

Upgrade the fixed package set together:

- `@0disoft/mensor-contract@0.3.0`
- `@0disoft/mensor-compiler@0.3.0`
- `@0disoft/mensor-cli@0.3.0`

## Consumer Impact

Existing text-codec contracts remain valid and retain their canonical
diagnostics. New contracts must pair each property schema with the matching
decoder. Checkbox decoders require explicit `trueValues` and `missing` values;
repeat decoders require an item decoder whose kind matches the array item
schema. Enum schema and decoder values must match in canonical order.

## Rollback

Projects that use only the text codec can pin the fixed package set back to
`0.2.1`. Contracts using the new decoder variants must be migrated back to text
bindings before downgrading; do not mix package versions.
