# Migrating to 0.6.0

Version `0.6.0` adds the explicit Hono RouteIndex producer while preserving
existing check, compile, contract, and runtime behavior.

Upgrade the fixed package set together:

- `@0disoft/mensor-contract@0.6.0`
- `@0disoft/mensor-compiler@0.6.0`
- `@0disoft/mensor-cli@0.6.0`
- `@0disoft/mensor-reference-runtime@0.6.0`

Projects with direct static Hono route calls can regenerate their configured
RouteIndex with:

```text
pnpm exec mensor index-hono-routes . --source src/routes.ts --receiver app
```

Repeat `--source` and `--receiver` as needed. The default output is
`mensor.route-index.json`. Dynamic paths, mounted routers, `on`, `all`, route
composition, optional chains, and empty extraction are rejected. Continue
using an independently maintained producer for other frameworks and preserve
application semantic tests regardless of a clean Mensor result.
