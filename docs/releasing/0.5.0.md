# Migrating to 0.5.0

Version `0.5.0` adds the `mensor compile` CLI command for atomic
RuntimeManifest v1 output. Existing `mensor check` behavior is unchanged.

## Packages

Upgrade the fixed public package set together:

- `@0disoft/mensor-contract@0.5.0`
- `@0disoft/mensor-compiler@0.5.0`
- `@0disoft/mensor-cli@0.5.0`
- `@0disoft/mensor-reference-runtime@0.5.0`

## Compile Impact

```text
pnpm exec mensor compile . --out .mensor/manifest.json
```

The output path must be relative to the selected project root. Compilation
emits no artifact while diagnostics remain. A successful write uses a temporary
file in the destination directory and replaces the target only after the bytes
are flushed. Existing output survives diagnostic, configuration, and write
failures.

`--json` writes the same canonical manifest bytes to stdout after the file is
committed. `--report-version` remains specific to `mensor check`.
The default `.mensor/` directory should normally be ignored as generated
output. Track or package a manifest only when the host's deployment contract
explicitly requires that artifact.

## Rollback

Projects that do not invoke `mensor compile` may pin the complete fixed package
set back to `0.4.0`. Remove any generated `.mensor/manifest.json` explicitly if
the host application should stop consuming it.
